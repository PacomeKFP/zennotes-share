# R1 - Accessibilite, themes, impression
Scope : lecture publique + admin, sans build, HTML + CSS + mini JS.

## A. Mode sombre propre
1. Centraliser les couleurs en variables semantiques sur `:root` : `--bg`, `--fg`, `--muted`, `--surface`, `--border`, `--link`, `--focus`. Interdire les couleurs en dur dans les composants.
2. Declarer `color-scheme: light dark` sur `:root` pour ajuster scrollbars et controles natifs.
3. Theme par defaut = systeme via `@media (prefers-color-scheme: dark)` qui surcharge les variables. Pas de JS requis pour ce cas.
4. Bascule manuelle par `html[data-theme="light"|"dark"|"auto"]`, avec `auto` = suivre le systeme. Priorite : choix manuel > systeme.
5. Persister le choix en `localStorage` (ex `zn-theme`) et poser `data-theme` par script inline dans `<head>` pour eviter tout flash au chargement.
6. Bouton de bascule accessible : `<button aria-pressed>` + `aria-label` explicite, libelle texte visible, cible 44x44 px, focus visible conserve.
7. Valider les contrastes dans les 2 themes avec les seuils de la section B avant de figer la palette. Ne jamais generer le theme sombre par simple inversion ou opacite.

## B. Accessibilite minimale
8. Contraste texte : 4.5:1 minimum en corps normal, 3:1 minimum en grand texte (24 px normal ou 18.66 px gras). Placeholder et texte d aide inclus.
9. Contraste non texte : 3:1 minimum pour bordures de champs, icones informatives et indicateurs de focus (etat focus vs non focus).
10. Base typo : 16 px minimum, `line-height` 1.5 mini, largeur de lecture 60 a 75 caracteres, espacement de paragraphe visible sans casser le zoom 200 %.
11. Cibles tactiles : 24x24 px minimum absolu (WCAG 2.2 AA), viser 44x44 px pour actions principales (copier lien, creer, supprimer, bascule theme). Si dense, garder un espacement tel qu un cercle de 24 px autour du centre ne chevauche aucune autre cible.
12. Focus visible partout : `outline: 2 px solid var(--focus)` minimum + `outline-offset: 2 px`, contraste 3:1. Ne jamais faire `outline: none` sans remplacement equivalent. Tester au clavier seul.
13. Semantique : un seul `h1` par page, hierarchie sans saut, `main`, `nav` avec `aria-label`, `label` explicite pour chaque champ, erreurs liees par `aria-describedby`, `lang="fr"` correct.
14. Formulaires admin au clavier : ordre logique, `Enter` soumet, `Esc` ferme les dialogues, focus piege puis rendu au declencheur, messages de statut en `role="status"` ou `aria-live="polite"`.
15. Respecter `prefers-reduced-motion: reduce` : couper transitions et animations non essentielles. Garder un ratio stable si le theme change pendant la saisie.

## C. Impression page lecture
16. Regrouper tout en `@media print` en fin de CSS. Masquer : nav, boutons, bascule theme, formulaires, messages flash : `display: none`.
17. Forcer lisible : `body { background: #fff; color: #000; }`, supprimer ombres et fonds, largeur 100 %, marges laterales a 0, `@page { margin: 2cm; }`.
18. Liens : souligner, afficher l URL des liens externes via `a[href^="http"]::after { content: " (" attr(href) ")"; }`, ne pas etendre les ancres internes ni les liens autour d images.
19. Sauts de page : `h2, h3 { break-after: avoid; }`, `pre, table, figure, blockquote { break-inside: avoid; }`, `img { max-width: 100%; }`, `table { font-size: 11 pt; }` si dense.
20. Ajouter un bloc print-only (titre, URL source, date) masque a l ecran et visible en print via `.print-only { display: none; }` inverse en print.
